# Shalivahana Connect

A community-based social and matrimonial platform.

## Tech Stack

### Frontend

- React.js
- React Router
- Axios
- Redux Toolkit
- Tailwind CSS

### Backend

- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Socket.IO

## Features

- Community member registration
- Government ID verification
- Member profiles
- Age-based profile information
- Member search
- Real-time chat
- Admin verification
